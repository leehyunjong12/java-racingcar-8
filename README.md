# java-racingcar-precourse

## 자동차 경주 (Racing Car)

초간단 자동차 경주 게임을 구현

---

## ✅구현 체크리스트

### View

- [x]  자동차 이름들을 입력받아 넘기기
- [x]  시도할 횟수 입력받아 넘기기
- [ ]  자동차 전진 상태 출력
- [ ]  우승자 명단 출력하기

### Controller (흐름)

- [x]  자동차 이름들 입력받기
- [x]  입력받은 문자열 나누기
- [x]  빈 문자열 다른 값으로 대체
- [x]  문자열 유효성 검사
- [x]  시도 횟수 입력 받기
- [x]  시도 횟수 유효성 검사
- [x]  자동차 모델들 생성
- 아래 반복
    - [ ]  자동차 조건별 전진
    - [ ]  전진 상태 출력
- [ ]  우승자 식별
- [ ]  우승자 명단 출력

### Service

- CarNameSplitterService
    - [x]  자동차 문자열을 구분자로 나누기
- FillEmptyCarNamesService
    - [x]  빈 자동차 문자열 대체값으로 채우기
- ValidatorService
    - 자동차 이름 예외
    - [x]  자동차 이름 길이가 5보다 클 때
    - [x]  중복된 이름이 있을 때
    - 시도 횟수 입력 예외
    - [x]  입력 횟수가 양수가 아닐 때
- RacingService
    - [x]  자동차 모델들 생성
    - [ ]  모든 자동차 조건별 전진
    - [ ]  모든 자동차 전진 상황 문자열 반환
    - [ ]  우승자 식별 후 반환

### Model

- RacingCar
- [x]  모델 구현
- (이름,전진 횟수, 전진 메서드, toString 함수 등)

### Repository

- RacingCarRepository
- [x]  자동차 모델 생성 및 리스트에 추가
- [x]  전체 자동차 조건별 전진
- [x]  현재 자동차들 상태 출력
- [x]  전진이 가장 큰 자동차들 반환

### 주의사항

- InputView 테스트는 System.in을 사용하는 구조 때문에,
  각 테스트는 반드시 독립적으로 실행해야 합니다.
- moveAllCarsRandomly 테스트는 Random 함수와 관련되어 있어,
  확률을 높이는 방법으로 테스트를 실행하였지만 실패 확률이 매우 적게 있습니다.
